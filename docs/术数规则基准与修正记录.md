## 一、奇门遁甲（时家 · 转盘法 · 拆补法）

### 1. 定局
- **阴阳遁**：冬至→夏至（12 个节气）为阳遁，夏至→冬至为阴遁。✅ 正确
- **节气用局表**（上/中/下元）：冬至惊蛰一七四、小寒二八五、大寒三九六、立春八五二、雨水九六三、春分三九六、清明四一七、谷雨五二八、立夏四一七、小满五二八、芒种六三九、夏至白露九三六、小暑八二五、大暑秋分七一四、立秋二五八、处暑一四七、寒露立冬六九三、霜降小雪五八二、大雪四七一。✅ 正确
- **三元定元（拆补法）**：**符头法**——甲己日为符头，每 5 日一元（60 时辰），上中下循环。符头日：甲子/甲午/己卯/己酉=上元、甲寅/甲申/己巳/己亥=中元、甲辰/甲戌/己丑/己未=下元。
  - ⚠️ 仅按日支（子午卯酉上元…）定元是**简化错误**：乙丑日符头法=上元（属甲子组）、日支法=下元；丙子日相反。
  - 依据：《神奇之门》原文、《御定奇门宝鉴》"考古法以甲子、己卯、甲午、己酉为符头"（[ctext](https://ctext.org/wiki.pl?if=en&chapter=250961#3)）、kinqimen `findyuen_dict`。
- 流派：拆补法（主流，本项目）／置闰法（芒种大雪后置闰，等符头换局）／茅山法（无三元概念）。

### 2. 地盘干
戊起局数宫，阳顺阴逆，沿**线性宫位序数 1→9**（坎坤震巽中乾兑艮离）。
分歧：古籍《烟波钓叟歌》"阳遁顺仪奇逆布"——阳遁结果与整体法相同，阴遁三奇位置相反。现代转盘/软件以整体法为准。✅ 正确

### 3. 天盘干
值符（旬首六仪）加时干宫，其余干按固定序列 戊己庚辛壬癸丁丙乙、**线性宫序阳顺阴逆**（序列不颠倒、只方向逆转）。
**自检铁律：甲子时（值符归位）天盘必须=地盘。** ✅ 已修复（原阴遁双颠倒）

### 4. 九星
值符星落时干宫，其余按 蓬芮冲辅禽心柱任英（数序原位）沿**线性宫序（含中五）阳顺阴逆**；天禽寄坤二。
分歧："九星恒顺"说（港台金函玉镜系，kinqimen 即此：环序星列蓬任冲辅英禽柱心且芮禽合并）；洛书飞宫序布。
✅ 已修复（原恒顺）

### 5. 八门
值使门从旬首宫起走 (时支序−旬首支序) mod 12 步，沿**八宫环序 1→8→3→4→9→2→7→6**（中五不入），阳顺阴逆；其余门按 休生伤杜景死惊开 顺/逆布；中五无门（死门寄坤二）。
分歧：部分流派按线性宫序 1,2,3,4,6,7,8,9 走宫。
硬约束：八门若线性布则死门与生门同落坤二冲突 → 只能环序。✅ 正确

### 6. 八神
**主流 = 顺序不变（值符腾蛇太阴六合白虎玄武九地九天）、仅方向阳顺阴逆**。
变体：(b) 阴遁顺序完全颠倒（值符九天九地玄武白虎六合太阴腾蛇）——阴盘奇门（王凤麟系）/茅山系，非转盘主流。
✅ 已修复（原阴遁双颠倒）

### 7. 值符星 / 值使门 —— 随局数变化
**通用规则：值符星 = 地盘旬首六仪所在宫的星；值使门 = 该宫的八门**（《神奇之门》："根据地盘上六甲中值班一甲所在宫位，即可找出与它对应的天盘上值班的九星之一，这就是值符；人盘上值班的八门之一，这就是值使"）。
固定表（甲子→天蓬/休门…甲寅→天心/开门）**只是阳遁一局的特例**，作普适表错误（反例：阳遁二局甲子旬=天芮/死门；阴遁一局甲戌旬=天英/景门）。
✅ 已修复（原固定表）

### 8. 四害
- **空亡**：时柱旬空地支对应宫（甲子戌亥→乾、甲戌申酉→兑、甲申午未→离坤、甲午辰巳→巽、甲辰寅卯→艮震、甲寅子丑→坎艮）。✅ 正确
- **击刑**：戊3己2庚8辛9壬4癸4 ✅ 正确（地支相刑：子卯、戌未、申寅、午午、辰辰、寅巳）
- **入墓**：乙6丙6戊6（戌墓乾）、丁8己8庚8（丑墓艮）、辛4壬4（辰墓巽）、癸2（未墓坤）——长生墓库派 ✅ 正确（分歧：五行墓库派如乙墓未→坤二）
- **门迫**：门克宫为门迫（吉门迫不吉、凶门迫更凶）✅ 正确

### 9. 排布宫序分工
天盘干/九星/地盘 = **线性 1→9（含中五）**；八门/八神 = **环序 1→8→3→4→9→2→7→6**（中五不入）。
硬约束：九星含中五天禽且甲子时天芮须@坤二 → 只能线性；八门若线性布则死/生同落坤二冲突 → 只能环序。
✅ 正确（本项目）

### 10. 验证案例（2024-06-21 10:00，丙辰日癸巳时甲申旬）
夏至后阴遁；符头甲寅（丙辰日前最近符头）→ 中元 → **阴遁三局**（日支法则错得阴六局）。
值符星 = 地盘庚宫（坎一）之星 = **天蓬**，落时干宫（兑七）；值使门 = 坎一之门 = **休门**（中五寄坤二规则）。与开源 kinqimen 输出逐宫一致（八神完全一致）。

## 二、梅花易数

### 1. 时间起卦（《年月日起例》）
```
上卦 = (年支数 + 农历月 + 农历日) mod 8      （余 0 取 8=坤）
下卦 = (年支数 + 农历月 + 农历日 + 时支数) mod 8
动爻 = (年支数 + 农历月 + 农历日 + 时支数) mod 6  （余 0 取 6=上爻动）
```
年支数：子1…亥12；时数：子时1…亥时12；卦数：乾1兑2离3震4巽5坎6艮7坤8。
经典验证——观梅占：辰5+十二12+十七17=34 → 34 mod 8 = 2 兑为上卦；+申时9=43 → 43 mod 8 = 3 离为下卦；43 mod 6 = 1 初爻动 → 泽火革。
闰月主流取当月数；分歧：取前/后月；改用节气月则无闰月问题。
✅ 已修复（原 lunar_python 集成失效导致公历降级）

### 2. 数字起卦
三数分别对上卦/下卦/动爻，除 8/8/6 取余，余 0 取 8/6。✅ 正确

### 3. 体用生克（《体用总诀》）
动爻所在卦为**用**、另一卦为**体**。五类：用生体吉、体生用泄耗凶、用克体大凶、体克用吉而费力、体用比和吉。✅ 正确
补充：互卦/变卦对体的生克参与断吉凶与应期快慢（生体之卦多则吉且应速，克体之卦多则凶）。

### 4. 互卦
本卦 2-4 爻为下互、3-5 爻为上互（自下而上），表事态中段。✅ 正确

### 5. 月令旺衰
**现代主流用节气月（月建）**：立春起寅月…惊蛰起卯月…（传统文本多用农历月，两派并存）。
旺相休囚死：当令者旺、令生者相、生令者休、克令者囚、令克者死。
十二个月分布（节气月）：寅卯辰木旺、巳午未火旺、申酉戌金旺、亥子丑水旺；土寄旺四季末（辰戌丑未各旺十八日，另有说法）。
✅ 已修复（原公历月近似且 3/6/9/12 月错判为土）

### 6. 应期（未实现，建议后续）
卦数法（乾1…坤8 定日月年）、动爻远近（初二三爻应近、四五上爻应远）、生体之卦旺相时应吉、克体之卦旺相时应凶、互变卦气取应、外应；另有"断应期十种方法"流传。

### 7. 断卦完整流程
起卦 → 定体用 → 体用生克断吉凶 → 排互变 → 互变生克参断 → 卦辞爻辞 → 月令旺衰 → 外应 → 断应期。
