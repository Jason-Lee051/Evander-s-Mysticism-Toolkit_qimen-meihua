玄学工具箱 - 使用说明
======================

一、快速开始
1. 将本压缩包解压到任意目录（路径中建议不要包含特殊字符）；
2. 双击「玄学工具箱.exe」启动程序。
   注：程序未做数字签名，首次运行时 Windows SmartScreen 可能弹出提示，
   请点击「更多信息」→「仍要运行」。

二、首次配置（必须）
1. 点击主界面「⚙️ LLM 设置」；
2. 填入你的 API Key（默认支持 DeepSeek，也可改为其他 OpenAI 兼容服务）；
3. 点击「保存」。设置会保存在本目录 config\llm_config.json 中。

三、目录说明
- 玄学工具箱.exe          主程序（双击运行）
- _internal\              程序运行所需的内部文件（请勿移动或删除）
- config\llm_config.json  你的个人 API 配置（保存设置后自动生成）
- config\llm_config.example.json  配置示例模板（仅供参考）

四、常见问题
Q：双击后没有反应 / 被杀毒软件拦截？
A：未签名的 exe 偶尔会被误报，请在杀毒软件中添加信任，
   或将整个解压目录加入白名单。

Q：想恢复默认设置？
A：关闭程序后删除 config\llm_config.json，重新打开即可。
